# Praktisk verktygsuppgift
I uppgiften använder jag mig av terminalen, , visual studio code och Git.
## Terminalen
I terminalen har jag skapat mappar och filer genom att använda mig av olika kommandon. pwd - för att se var i filsystemet jag befinner mig, mkdir - för att skapa ny mapp, cd - för att byta mapp, touch - för att skapa en ny fil. 
### Visual studio code 
I visual studio code har jag arbetat med projektet.
#### Git-kommandon i uppgiften
* git push - skickar upp aktuell branch till git servern
* git status - visar status
* git init - skapar ett repository
* git add - lägger till filändringar
* git commit -m - "Första commit" - sparar ändringar 
##### repository, commit och versionshistorik
Repository är en lagringsplats där ett projekts filer, mappar och ändringar sparas.
Commit är en sparad version av ett projekts filer.
Versionshistorik är historik över alla ändringa som gjorts i ett projekt.
